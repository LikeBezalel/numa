# NÜMA Açaí Website

Premium, conversion-focused marketing site for a boutique açaí event catering brand.

## Stack
- Next.js (App Router)
- TypeScript
- Tailwind CSS

## Pages
- Home
- Experience
- Gallery
- Testimonials
- About
- Inquiry
- Contact

## Inquiry Flow
The booking intake routes to the provided Google Form and is also embedded on the inquiry page for a seamless UX.

## Local Development
```bash
npm install
npm run dev
```
