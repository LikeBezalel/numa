# NÜMA Açaí Website

Boutique event catering website built with Next.js App Router, TypeScript, and Tailwind CSS.

## Pages
- Home
- Experience
- Gallery
- Testimonials
- About
- Inquiry
- Contact

## Getting Started
```bash
npm install
npm run dev
```

## Notes
- Inquiry flow is connected to the provided Google Form.
- Visual placeholders are intentionally structured so real brand photos can be dropped in quickly.
